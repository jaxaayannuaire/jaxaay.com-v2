# Support

## Bugs techniques

Utiliser le modèle **Bug report** dans GitHub Issues.

## Évolutions

Utiliser le modèle **Feature request**.

## Questions d'architecture

Les décisions structurantes doivent être discutées avant implémentation et, si elles sont retenues, documentées dans un ADR.

## Données sensibles

Ne jamais publier dans une issue :

- mots de passe ;
- clés API ;
- tokens ;
- données KYC ;
- fichiers clients confidentiels ;
- informations personnelles privées.
