# Politique de sécurité

## Versions supportées

Le projet est en pré-développement. Les versions supportées seront précisées lors de la première release publique.

## Signaler une vulnérabilité

Ne pas ouvrir une issue publique contenant :

- mot de passe ;
- token ;
- secret OAuth ;
- clé API ;
- données KYC ;
- informations personnelles sensibles ;
- détails exploitables d'une vulnérabilité non corrigée.

Utiliser le canal privé de sécurité du dépôt GitHub lorsque celui-ci sera activé, ou le canal interne défini par Jaxaay Group.

## Périmètre prioritaire

Les signalements concernant les éléments suivants sont prioritaires :

- isolation multi-tenant ;
- authentification / autorisation ;
- exposition de contacts privés ;
- KYC ;
- uploads ;
- imports ;
- webhooks ;
- External Profiles ;
- tokens OAuth ;
- injections ;
- accès cross-organization ;
- contournement des Policies.

## Divulgation

La divulgation publique d'une vulnérabilité doit attendre la disponibilité d'un correctif et la validation par l'équipe projet.
